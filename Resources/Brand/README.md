# NegiPlayer icon

Both native apps use one opaque icon master: `NegiPlayer-Icon-Master.png`. The iOS asset catalog contains its 1024-pixel export; `../AppIcon.icns` contains standard macOS sizes. Platform masks add their own corners.

Created with Codex's built-in ImageGen on 2026-10-11. This design brief records the intended direction, not a claim of trademark clearance:

> Create a neutral app icon for NegiPlayer, a modern high-fidelity music player. A bold, distinctive N monogram with a subtle leek/leaf cue from “Negi” and a small negative-space play triangle. Graphite background, warm off-white strokes and restrained sage teal. No character imagery, no Miku silhouette, no lettering or wordmark, no headphone clip-art. Premium, calm, geometric, highly legible at small sizes. One centered emblem around 58 percent of the square canvas. Full bleed opaque square master, no baked rounded corners, no mockup or surrounding frame. Shared visual identity for macOS and iOS; theme colors belong to the UI.

No third-party character artwork is included. Resizing and icon-container packaging preserve the generated image composition.
